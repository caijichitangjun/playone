# 平面塔防（Plane Tower Defense）

一个 2D 平面塔防游戏，**一套代码同时跑在 Android 和 iOS 上**。纯前端、零依赖、零资源文件（图形用 Canvas 现画、音效用 WebAudio 合成），整个站点不到 300 KB。

## 直接玩

👉 **https://caijichitangjun.github.io/playone/**

手机打开后加到主屏幕，就是全屏 App 体验，而且**支持离线玩**：

- **iPhone**：用 Safari 打开 → 分享 → 添加到主屏幕
- **Android**：用 Chrome 打开 → 菜单 → 安装应用（manifest 里声明了横屏，装好后会自动锁横屏）

## 玩法

守住城堡，别让敌人走到终点。

| 操作 | 说明 |
| --- | --- |
| 建造 | 点底部选一种塔 → 点地图空地放置（可连续摆塔） |
| 查看/升级 | 点已建好的塔 → 升级、出售、切换攻击优先级 |
| 提前召唤 | 点顶部「第N波」提前开下一波，提前越多奖励金币越多 |
| 速度 | 顶部 `1×` 切换 1× / 2× / 3× |

**核心思路**：减速（冰塔）留住敌人 → 高输出（箭塔/炮塔）在减速区集中火力 → 毒塔/电塔无视护甲啃重甲和首领。飞行单位会沿地图上那条**紫色虚线航线**走直线抄近路。

### 内容

- **3 个关卡**（递进难度，通关解锁下一关）：青草平原 12 波 / 荒漠峡谷 16 波（双线合流）/ 熔岩要塞 20 波（长蛇阵 + 飞行抄近路）
- **5 种防御塔**各 3 级：箭塔 / 炮塔（范围伤害）/ 冰塔（减速）/ 电塔（连锁、无视护甲）/ 毒塔（持续掉血、无视护甲）
- **7 种敌人**：小兵 / 疾行者 / 虫群 / 重甲（有护甲）/ 飞行（走直线）/ 医官（治疗同伴）/ 首领（每 5 波）

## 仓库结构

本仓库根目录就是 GitHub Pages 的站点根（发布源：`main` / `(root)`），文件由本地源码构建生成，建议不要直接手改：

```
index.html            游戏外壳（HUD 用 DOM，画布只画游戏世界）
styles.css            响应式样式：刘海安全区、横竖屏、平板黑边自适应
sw.js                 Service Worker：离线缓存整个应用外壳
manifest.webmanifest  PWA 清单：应用名、图标、全屏、锁横屏
icons/                应用图标（脚本生成，非设计资源）
src/                  游戏源码（纯 ES Module，无任何第三方依赖）
```

几点技术说明：

- 世界比例做成 24:11，贴近手机横屏比例，画面几乎铺满屏幕；HUD 浮在画面上方，平板 4:3 时正好落进上下黑边
- 固定步长主循环（60Hz 累加），不同刷新率与加速档位下表现一致
- Service Worker 用 manifest 的位置反推应用根目录，所以在 `/playone/` 这种子目录部署下也能正确工作
- 游戏逻辑层完全不依赖 DOM，可以在 Node 里无头跑完整对局做平衡验证
